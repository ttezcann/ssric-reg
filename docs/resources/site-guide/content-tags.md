# [[Content tags]]
- Content tags appear as colored chips in the left sidebar.
    - Clicking a content tag chip in the home page opens the pane.
    - This makes common content types easy to reach.
        - ![Home page sidebar showing colored content-tag chips such as `#code`, `#output`, and `#interpretation`; an arrow points to the tags.](../../assets/attachments/resources/site-guide/content-tags/content-tags.png)
    - When a content tag chip is clicked on a page, results are grouped by page.
        - The current page appears first.
        - The clicked section appears first inside that page.
            - ![Clicking `#output` opens a pane listing matching output sections, grouped by page, with the current page shown first.](../../assets/attachments/resources/site-guide/content-tags/content-tags-output.png)
