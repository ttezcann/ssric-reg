# [[Dummy variable]] definition
- Linear regression uses a continuous outcome variable. Factor variables can be continuous or categorical.
    - In the social sciences, we often work with categorical factor variables whose numbers are category codes rather than measurements.
- A [[dummy variable]] is a variable coded **zero (0)** or **one (1)** to represent a category in a regression model.
    - Dummy variables allow us to compare categories. For example, we can compare the predicted personal income of **females** with that of **males**.

# Examples
## Example: Rent prices
- Imagine a linear regression analysis in which we examine the association between **population of the city** (continuous) and **house type** (categorical: 1 for Townhouse, 2 for Studio) and the **monthly rent** (outcome variable).
- We want to know whether predicted rent differs between townhouses and studios and how it is associated with the population of the city.
    - ```mermaid

<!-- slide-break -->
- If we include the original house type variable in our model as it is, the linear regression model will incorrectly assume that:
    - Living in a "Studio" **(2)** is somehow **twice** the value of living in a “Townhouse” **(1)**. 
    - This would be similar to estimating the coefficients for age; 20-year-old and 40-year-old respondents (40 is twice 20).
<!-- slide-break -->
- **The solution:**
    - We use [[dummy variable]]s, which have only two values, **zero (0)** and **one (1)**.
        - In the **townhouse** dummy variable, **1** means townhouse and **0** means not townhouse.
        - In the **studio** dummy variable, **1** means studio and **0** means not studio.
            - We create both variables to learn their coding, but a regression model with an intercept needs only one of these two dummy variables.
            - | respondent | Original variable | Dummy variable 1 | Dummy variable 2 | 
              |:----------:|:-----------------:|:----------------:|:----------------:|
              |            | housetype         | townhouse        | studio           |
              | 1          | 2 (studio)        | 0                | 1                |
              | 2          | 1 (townhouse)     | 1                | 0                |
              | 3          | 2 (studio)        | 0                | 1                |
              | 4          | 1 (townhouse)     | 1                | 0                |
              | 5          | 2 (studio)        | 0                | 1                |
              | 6          | 1 (townhouse)     | 1                | 0                |

## GSS example: Sex
- The original **sex** variable uses **1=Male** and **2=Female** in GSS. 
- If we have a variable for sex with two responses (1=Male and 2=Female), we can't use the original values of 1 and 2, and interpret that as meaning being female is somehow two times of that being male.
    - The solution is to use dummy variables - variables with only two values, zero and one. 
- It does make sense to create a variable called “male" and interpret it as meaning that someone assigned a 1 on this variable is male and someone with a 0 is not. 
    - Following this procedure, we also create a separate “female” dummy variable to show the effects of being female on the outcome variable, such as "personal income."
        - | respondent | Original variable | Dummy variable 1 | Dummy variable 2 | 
        |:----------:|:-----------------:|:----------------:|:----------------:|
        |            | sex               | male             | female           |
        | 1          | 1 (male)          | 1                | 0                |
        | 2          | 1 (male)          | 1                | 0                |
        | 3          | 2 (female)        | 0                | 1                |
        | 4          | 1 (male)          | 1                | 0                |
        | 5          | 2 (female)        | 0                | 1                |
        | 6          | 2 (female)        | 0                | 1                |

### [[Omitting dummy variable]]
- **Then, which dummy variable(s) to include and which one(s) to omit?**
    - We include **male** if we want to compare males with females on predicted personal income.
    - We include **female** if we want to compare females with males on predicted personal income.
        - Either choice produces the same predicted values when the same respondents and other factors are used.
            - We include **one** dummy variable and omit the other as the comparison category.
                - If both are included, R cannot estimate both coefficients separately and it will remove the last added dummy variable.
<!-- slide-break -->
- **Omitting a dummy variable does not mean removing respondents from that category:**
    - We actually attribute a significant meaning to the omitted dummy variable that:
        - The omitted variable becomes our [[comparison dummy variable]]:
            - Its category remains in the data and is used as the reference for interpreting the included dummy variable.
                - !!! note "Interpretation of dummy variables"
                    **Being male** *(included dummy variable)* is associated with $**11,788** higher predicted personal income than **being female** *(omitted - comparison dummy variable)*.

                    **OR**

                    **Being female** *(included dummy variable)* is associated with $**11,788** lower predicted personal income than **being male** *(omitted - comparison dummy variable)*.
    - Likewise, 
        - if we create two dummy variables using a single original variable:
            - We need to **include one**, and **omit one**.
        - if we create three dummy variables using a single original variable:
            - We need to **include two**, and **omit one**.
        - if we create four dummy variables using a single original variable:
            - We need to **include three**, and **omit one**.
