# [[Linear regression assumptions]] - Overview
- **Assumption 1: Homoscedasticity**
    - The errors our model makes should be about the same size across different predicted values.
        - When the size of the errors changes, we call it heteroscedasticity.
- **Assumption 2: Multicollinearity**
    - The factor variables should not be too strongly correlated with each other.
        - When they are, it becomes difficult to separate their relationships with the outcome variable.
- **Assumption 3: Linear relationship**
    - There should be a linear relationship between the outcome variable and continuous factor variables.
        - This means that a straight line should describe the relationship reasonably well.
- **Assumption 4: Normal distribution**
    - The continuous variables used should display approximately normal distribution; 
        - Most people's values should be clustered around the middle, not at the very high or very low ends.
- **Check 5: At least 10% of the cases**
    - Enough sample size for each category of the dummy variables; 
        - In this class, we check whether the categories have at least 10% of the responses.
<!-- slide-break -->
## Assumption 1: Homoscedasticity
- [[Homoscedasticity]] means that the errors in our regression model have about the same spread across different predicted values.
    - An error is the difference between an actual value and the value predicted by the model.
    - Linear regression aims to create a straight-line model that best fits the data.
        - ![Two small scatterplot diagrams compare variance patterns: one shows homoscedasticity with data points evenly spread around a horizontal line across all x-values, and the other shows heteroscedasticity with the spread of points increasing as x-values increase. Arrows and lines illustrate constant versus changing variability across the range of the independent variable.](../assets/attachments/modules/15.-regression-assumptions-diagnostics/homoscedasticity.png)
<!-- slide-break -->
    - **Several reasons may contribute to the [[heteroscedasticity]] issue:**
        - **Outliers:** Extreme values in data can lead to heteroscedasticity.
        - **Nonlinear relationships:** When the relationship between the independent and dependent variables is nonlinear (i.e., curvilinear), it can lead to heteroscedasticity.
        - **Omitted variables:** If important variables are omitted from the regression model, they can lead to heteroscedasticity.
            - !!! note "Addressing the heteroscedasticity"
                - For this module, we will try removing some variables and then check the model again. Removing variables does not always solve this issue.
<!-- slide-break -->
## Assumption 2: Multicollinearity
- [[Multicollinearity]] occurs when two or more factor variables in a regression model are strongly correlated with each other.
    - This makes it difficult to separate their individual relationships with the outcome variable.
        - ![A diagram uses overlapping circles to illustrate multicollinearity, showing two variables with overlapping areas representing shared variance. The figure contrasts slightly correlated variables with highly correlated variables by increasing overlap between the circles.](../assets/attachments/modules/15.-regression-assumptions-diagnostics/multicollinearity.png){width="500"}
<!-- slide-break -->
    - **Several solutions exist for [[multicollinearity]] issue:**
        - Removing one of the strongly correlated variables
        - Creating an index variable using strongly correlated variables
        - Centering variables (subtracting the mean value from each observation)
        - Lasso regression (L1 Regularization)
            - !!! note "Addressing the multicollinearity issue"
                - For this module, we will remove some strongly related variables and check the model again.
<!-- slide-break -->
## Assumption 3: Linear relationship
- The term "[[linearity]]" in linear regression means that a straight line can reasonably describe the relationship between a continuous factor variable and the outcome variable.
    - A [[curvilinear relationship]] between a continuous factor and an outcome variable may not be described well by a straight line.
        - ![A scatterplot shows a curved, non-linear relationship between variables X and Y, with points forming an inverted U-shaped pattern rather than a straight line. A red X marks the plot to indicate that this curvilinear pattern violates the linearity assumption of linear regression.](../assets/attachments/modules/15.-regression-assumptions-diagnostics/curvilinear.png)
<!-- slide-break -->
    - **Several solutions exist for [[curvilinear relationship]] issue:**
        - Recoding the variable into categorical
        - Polynomial regression
        - Adding interaction terms
        - Trying a different way to represent the relationship in the model
            - !!! note "Addressing the curvilinear relationship"
                - For this module, we will try removing some variables and check the model again. In types of modeling, curved relationships can also be included in regression.
<!-- slide-break -->
